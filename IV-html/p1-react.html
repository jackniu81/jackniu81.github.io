useEffect hook on component initialization effect that runs once when the App component mounts

执行顺序： // 输出顺序： // 1. 组件渲染开始 // 3. 组件渲染结束 // 2. useInsertionEffect - DOM 更新前 // 4. useLayoutEffect - DOM 更新后，重绘前 // 6. useEffect - 重绘后，异步执行

需要操作 DOM？ ├─ 是 → 需要读取布局信息？ │ ├─ 是 → useLayoutEffect (防止闪烁) │ └─ 否 → useEffect (异步操作) └─ 否 → 需要 CSS-in-JS？ ├─ 是 → useInsertionEffect └─ 否 → useEffect

需要 DOM 引用？ ├─ 是 → useRef └─ 否 → 持久化值？→ useRef

需要暴露方法给父组件？ ├─ 是 → useImperativeHandle + forwardRef └─ 否 → 不需要

总结

Hook 主要用途 执行时机 性能影响
useEffect 数据获取、订阅、异步操作 异步 (重绘后) 最小
useLayoutEffect DOM 布局、防止闪烁 同步 (重绘前) 可能阻塞
useInsertionEffect CSS-in-JS、动态样式 同步 (DOM 更新前) 最小
useRef DOM 引用、持久化值 渲染时 无
useImperativeHandle 暴露组件方法 渲染时 无

最佳实践：

  1. 默认选择 useEffect
  2. 需要防止闪烁时用 useLayoutEffect
  3. 开发 CSS-in-JS 库用 useInsertionEffect
  4. 需要 DOM 引用用 useRef
  5. 需要暴露方法用 useImperativeHandle

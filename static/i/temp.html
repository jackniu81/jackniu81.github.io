AI Agent / LLM 里的「偏移（drift，也叫输出漂移、任务漂移）」

你前面做文章生成Agent、RAG写稿最容易碰到的问题：模型跑着跑着，慢慢偏离最开始设定好的目标、风格、约束、身份，就叫偏移（drift）。 区分两个容易混的：模型权重漂移（weights drift） 和 对话/推理偏移（prompt drift，你业务里说的偏移基本都是这个） 我们聊的是Agent流水线、文章生成场景的偏移，不是机器学习特征漂移。

1. 什么是偏移（通俗例子，贴合你的私活）

你给Agent设定：

身份：企业SEO文案；风格平实；固定字数；必须基于产品手册；禁用夸大话术；每篇围绕指定关键词

跑几轮之后慢慢出现：

  • 越写越飘，开始加营销大话、编造参数（脱离RAG素材）
  • 风格变了：本来专业平实，后面变得很口语、像小红书种草文
  • 主题跑偏：让写A产品，写着写着扯到别的产品
  • 无视规则：明明要求800字，后面随便写200字、或者超到2000字
  • 多轮Agent循环里，后面步骤忘掉前面的约束条件

✅ 本质：大模型上下文里的约束信息被稀释、权重被后面内容盖过；或者模型本身偏好强于你的指令。 MoE模型（gpt-oss-120b、Qwen3.5-122B这种）更容易出现：路由到不同专家，输出风格波动大，偏移会更明显。

2. 偏移分3类（做文章Agent要分开治理）

① Prompt / 上下文漂移（最常见，你项目90%都是这个）

多轮循环、长上下文，系统提示词、品牌规范、约束条件被挤到上下文窗口远端，模型“看不见、记不住”规则。 典型场景：批量连续生成几十篇文章、多步骤Agent（检索→摘要→扩写→润色→校验），越往后越不守规矩。

② 风格漂移（写内容接单最痛）

同一个任务，不同轮次口吻、结构、句式不一致。 根源：基座模型本身有先验偏好；RAG召回的范文风格参差不齐，模型被范文带偏。

③ 事实/资料漂移（幻觉的一种）

脱离给定参考文档，自己瞎编，不再忠于客户给的产品资料。 也就是：RAG召回失效、模型不信任检索片段，优先用内部参数知识输出。

补充：不是幻觉=偏移。幻觉是编假内容；偏移是慢慢丢掉你预设的约束和目标，偏移最后往往带来幻觉。

3. 为什么 MoE（gpt-oss-120b / Qwen3.5-122B-A10B）更容易偏移？

MoE是路由激活不同专家层：

  • 不同专家擅长东西不一样；
  • 同样query，这次路由专家A，下次专家B；
  • 专家A写文严谨，专家B喜欢自由发挥； → 表现就是：同样配置、同样prompt，两次输出差别很大，也就是漂移、不稳定。 稠密大模型相对稳定一点，但长上下文多轮之后照样会偏移。

4. 一套落地防偏移方案（适配你的LangGraph文章Agent，接单直接用）

方案1：约束隔离，不要把规则埋在历史对话里（最有效）

❌ 错误做法：系统提示词放最前面，然后不断追加生成内容，历史越堆越长，规则被压到底部。 ✅ 正确做法：

  • 每一轮生成，独立带上完整约束块（品牌口吻、禁用词、结构模板、字数、写作要求），不是只发新query；
  • 把【固定规则块】和【动态输入（关键词+召回参考资料）】物理分开。>

LangGraph里：系统prompt作为独立节点常量，每次调用LLM都原样带上，不依赖对话记忆。

方案2：增加校验节点（你流水线必加）

生成完不直接交付，单独一个LLM校验节点： 校验prompt模板示例：

你是审核器，对照下面规则检查文章： 规则列表：xxx 参考资料：xxx 待审核文章：xxx 判断：是否偏移主题 / 是否风格不符 / 是否编造不在资料里的信息；不符合就输出【不通过】+修改指令。 不通过 → 回传给生成节点重写；超过重试次数直接标记失败告警。 这个节点就是专门用来拦截偏移。

方案3：RAG侧控制，防止范文带偏

  • 召回的时候做rerank，过滤风格杂乱、无关范文；
  • 不要一次塞太多不同风格的参考文本进去；
  • 给客户准备少量标准范文模板，优先召回标准模板，而不是随便拉历史旧稿。

方案4：指令权重加强

关键约束用结构化标记，比如<RULE>...</RULE>，在prompt里明确告诉模型：标签内内容优先级最高，不能忽略。 很多模型对标记块有注意力偏向，不容易丢约束。

方案5：少用超长连续对话

批量生成文章：尽量做成无状态单轮调用，而不是同一个对话session里循环生成上百篇。 同一个session越长，漂移越严重。

进阶方案（客户要求极高一致性时）

做DPO/偏好微调：拿【合规不偏移的样本】和【偏移坏样本】做偏好微调，压模型的自由发挥倾向。 适合付费高、长期稳定的垂直客户；小私活一般不用，靠节点校验足够。

5. 接单话术（给客户解释偏移）

“大模型有漂移特性，连续产出内容的时候，很容易慢慢偏离咱们定好的品牌风格、产品口径。我们这套Agent流水线加了独立校验节点、固定规则注入，每次生成都会复核，保证几十上百篇内容口径统一，不会越写越飘。”

6. 一句话区分，避免混淆

  • 偏移drift：忘记规则、跑偏目标、风格不一致（行为飘）
  • 幻觉hallucination：编造不存在事实（内容假）
  • 温度temperature：控制随机性；温度高更容易偏移，但偏移≠温度高，低温度照样会偏移（长上下文遗忘约束）

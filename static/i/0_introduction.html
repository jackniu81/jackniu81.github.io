自我介绍

概览

我之前在戴尔，负责官网特卖平台，团队 10 人，其中担任亚洲技术负责人 8 人，负责支持全球 20 多个国家、面向 toC 端与 toB 端的特卖业务。

前台 Web

  • 支持新的需求、适配不同国家的业务需求与政策法规；
  • 优化页面性能与响应速度，核心指标参考 Core Web Vitals（CWV）；
  • 推进无障碍访问（A11y）、SEO 优化与用户行为埋点跟踪；
  • 支撑大流量并发与高可用——黑五峰值。源站 500 TPS、页面响应 0.5s；前端还有akamai，进一步提升性能。
  • 采用微前端（Micro-frontend）架构；
  • 部署在 PCF（Pivotal Cloud Foundry），便于扩展。

后台服务

  • 基于微服务架构的一系列服务；
  • 通过 Kafka / RabbitMQ（RMQ）完成上下游系统交互。

Admin 管理后台

  • 用于管理特卖分类、内容与推广信息；
  • 集成 AI Agent，构建长尾管理（longtail admin）能力；
  • 支持不常用、临时性的查询与校验场景；
  • 周边 50+ API 封装为工具（tools），设计文档、Spec 文档及预设查询步骤用于检索增强生成（RAG）。
  • 通过自然语言描述查询周边系统与特卖数据，用于数据校验、线上排错和生成简易报表；

我的工作

  • 约 80% 时间投入具体执行，
  • 覆盖全流程： 需求 → 设计 → 实现 → cicd部署 → 测试 → 上线 → 支持的工作；
  • 基于 Spec-Driven Design（SDD）的AI编程：明确目标，需求落地后推动快速自动发布；实施阶段分步骤推进，每步 Review，防止跑偏。

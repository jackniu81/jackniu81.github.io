Python 教程：给 TypeScript 开发者

你已经会 TypeScript，这篇教程不重复"什么是变量、什么是函数"，只讲 Python 和 TS 的差异、Python 的独特玩法、以及 TS 开发者最容易踩的坑。每节都附 TS 对比代码，快速建立映射。

0. 核心差异速览（先建立心智模型）

维度 TypeScript Python
运行时 编译为 JS，在 Node/浏览器运行 解释执行（.py → 字节码 → PVM）
类型系统 静态类型，编译期检查，运行时擦除 动态类型，type hints 仅作提示，运行时不检查
包管理 npm / package.json pip / requirements.txt / pyproject.toml
环境隔离 node_modules（每项目） venv / conda（虚拟环境）
异步模型 Promise + event loop（libuv） asyncio + event loop（单线程协作式）
空值 null / undefined 只有 None
相等 === / == ==（值相等）/ is（身份相等）
模块 ES Modules（import/export） import / from ... import
作用域 块级作用域 {} 函数级作用域（无块级），LEGB 规则
缩进 不敏感（用 {}） 敏感，缩进就是语法

一句话总结：Python 是"动态类型 + 缩进语法 + 万物皆对象 + 强制可读"的语言，TS 开发者最大的转变是从"编译期抓错"转向"运行时 + 测试抓错"。

1. 环境与工具链（对应 npm / node）

1.1 安装 Python

python --version   # 或 python3 --version，建议 3.10+

1.2 虚拟环境（对应 node_modules）

Python 没有项目级 node_modules，用虚拟环境隔离依赖：

python -m venv .venv          # 创建虚拟环境（对应 npm init）
source .venv/bin/activate     # Mac/Linux 激活
.venv\Scripts\activate        # Windows 激活
deactivate                    # 退出

激活后终端前缀会显示 (.venv)，此时 pip install 只装到当前环境。

1.3 包管理（对应 npm）

pip install requests          # 安装包（对应 npm install）
pip install requests==2.31.0  # 指定版本
pip freeze > requirements.txt # 导出依赖（对应 package.json dependencies）
pip install -r requirements.txt  # 按文件安装

现代项目用 pyproject.toml（对应 package.json）+ poetry 或 uv（更快的现代包管理器，类似 pnpm）。

1.4 运行代码

python script.py     # 运行文件
python -i script.py  # 运行后进入交互模式（REPL）
python               # 直接进 REPL，类似 node

2. 基础语法

2.1 变量与赋值

Python 变量不需要声明类型，直接赋值：

name = "Alice"      # 字符串
age = 25            # 整数
pi = 3.14           # 浮点
is_ok = True        # 布尔（注意首字母大写！）
nothing = None      # 对应 null/undefined

对比 TS：

let name: string = "Alice";
const age = 25;
let nothing: null = null;

Python 没有 const，约定全大写下划线表示常量：MAX_RETRY = 3。

2.2 缩进就是语法

Python 不用 {}，用缩进表示代码块（通常 4 空格）：

if age >= 18:
    print("成年")      # 缩进 4 空格 = 代码块
    print("可以投票")
else:
    print("未成年")

坑：缩进错误会直接报 IndentationError，混用 Tab 和空格也会报错。TS 开发者一定要适应"没有花括号"。

2.3 控制流

# if-elif-else（对应 if/else if/else）
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

# for 循环（对应 for...of，直接迭代元素，不是索引）
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# 需要索引用 enumerate（对应 forEach 的 index）
for i, fruit in enumerate(fruits):
    print(i, fruit)

# while 循环
while count < 10:
    count += 1

# 三元表达式（对应 condition ? a : b，语序不同！）
result = "及格" if score >= 60 else "不及格"
# TS: const result = score >= 60 ? "及格" : "不及格";

2.4 字符串

s = "hello"
f"{s} world"        # f-string，对应模板字符串 `${s} world`
s.upper()           # 方法调用，和 TS 类似
s.split(",")        # 分割
",".join(["a","b"]) # 拼接（注意是分隔符.join(列表)，不是 list.join）
len(s)              # 内置函数，不是 s.length

坑：Python 字符串是不可变的，s[0] = "H" 会报错；要修改需重新赋值或用 list(s)。

3. 数据结构（对应 TS 的 Array/Object/Map/Set）

3.1 list（对应 Array）

arr = [1, 2, 3]
arr.append(4)       # push
arr.pop()           # pop
arr[0]              # 索引访问
len(arr)            # length
arr[1:3]            # 切片，对应 slice(1,3)，返回 [2,3]
arr + [4, 5]        # 拼接，对应 concat
"a" in arr          # 对应 includes（但 list 是 O(n)）

推导式（Python 特色，对应 map/filter 的语法糖）：

[x * 2 for x in range(5)]              # [0,2,4,6,8] 对应 map
[x for x in range(10) if x % 2 == 0]   # 过滤，对应 filter

3.2 dict（对应 Object / Map）

d = {"name": "Alice", "age": 25}
d["name"]             # 访问，key 不存在会报错
d.get("email", "无")  # 安全访问，带默认值（对应可选链 ?.）
d["city"] = "Beijing" # 新增/修改
del d["age"]          # 删除
"name" in d           # key 是否存在（对应 key in obj）
d.keys(), d.values(), d.items()  # 对应 Object.keys/values/entries

Python 3.7+ dict 保持插入顺序（类似 TS 的 Map），且 key 必须是可哈希的（不可变类型）。

3.3 set（对应 Set）

s = {1, 2, 3}
s.add(4)
s.remove(1)
1 in s               # O(1) 查找
s & {2, 3, 4}        # 交集
s | {4, 5}           # 并集

集合去重极快：list(set([1,1,2,3])) → [1,2,3]。

3.4 tuple（TS 没有直接对应）

t = (1, 2, 3)        # 不可变的 list
x, y, z = t          # 解构赋值（对应 [x,y,z] = arr）
x, y = y, x          # 交换变量，不需要临时变量！

函数返回多个值时，Python 底层返回的就是 tuple：

def get_user():
    return "Alice", 25  # 实际返回 ("Alice", 25)
name, age = get_user()  # 解构

4. 函数

4.1 基本定义

def add(a, b):
    return a + b

对比 TS：

function add(a: number, b: number): number { return a + b; }

4.2 默认参数

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"

坑：默认参数在函数定义时求值一次，可变对象（list/dict）会被所有调用共享（详见面试题 106）。

4.3 *args 和 **kwargs（对应 rest 参数）

def func(*args, **kwargs):
    print(args)    # tuple：位置参数打包
    print(kwargs)  # dict：关键字参数打包

func(1, 2, a=3, b=4)
# args = (1, 2), kwargs = {'a': 3, 'b': 4}

对比 TS：

function func(...args: number[]) {}  // 只有位置参数 rest

Python 的 **kwargs 相当于 TS 中没有的"关键字参数 rest"。

调用时也可以解包：

nums = [1, 2, 3]
func(*nums)        # 对应 func(...nums)
params = {"a": 1}
func(**params)     # 对应 func({...params})，但作为关键字参数

4.4 lambda（对应箭头函数）

add = lambda a, b: a + b
# 对应 const add = (a, b) => a + b;

lambda 只能写一个表达式，不能有语句和多行。复杂逻辑用 def。

4.5 高阶函数

list(map(lambda x: x*2, [1,2,3]))   # 对应 arr.map(x => x*2)
list(filter(lambda x: x>1, [1,2,3]))# 对应 arr.filter(x => x>1)
from functools import reduce
reduce(lambda a,b: a+b, [1,2,3])    # 对应 arr.reduce((a,b)=>a+b)

但 Python 更推荐用推导式代替 map/filter，更可读。

5. 面向对象

5.1 类定义

class Dog:
    def __init__(self, name):   # 对应 constructor
        self.name = name        # self 对应 this，但必须显式写

    def bark(self):             # 方法第一个参数永远是 self
        print(f"{self.name} says woof!")

d = Dog("Buddy")
d.bark()

对比 TS：

class Dog {
    constructor(public name: string) {}
    bark() { console.log(`${this.name} says woof!`); }
}

坑：Python 的 self 必须显式写在每个方法参数里，调用时不用传。忘记写 self 是新手最常见错误。

5.2 继承

class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        pass

class Cat(Animal):          # 继承写在括号里，对应 extends
    def speak(self):        # 重写，不需要 override 关键字
        print(f"{self.name} says meow")

    def __init__(self, name, color):
        super().__init__(name)  # 对应 super(name)
        self.color = color

Python 支持多继承：class C(A, B):，通过 MRO（C3 算法）确定方法查找顺序。

5.3 魔术方法（对应 TS 的 Symbol 特殊方法）

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __str__(self):           # 对应 toString()
        return f"({self.x}, {self.y})"
    def __eq__(self, other):     # 对应 valueOf / ===
        return self.x == other.x and self.y == other.y
    def __add__(self, other):    # 运算符重载，对应 Symbol.plus
        return Point(self.x + other.x, self.y + other.y)

魔术方法以双下划线开头结尾，Python 一切行为都可通过它们自定义。

5.4 没有接口，用抽象类或鸭子类型

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self): ...

class Circle(Shape):
    def area(self): return 3.14 * self.r ** 2

Python 更常用鸭子类型：不要求继承，只要有 area() 方法就能用。

6. 类型系统（type hints vs TS 类型）

6.1 基本用法

Python 3.5+ 支持类型注解，但运行时不检查：

def greet(name: str) -> str:
    return f"Hello {name}"

age: int = 25

对比 TS：TS 编译期强制检查，Python 的类型注解只是给 IDE 和工具看的，运行时传错类型不会报错。

6.2 常用类型

from typing import List, Dict, Optional, Union, Any

# Python 3.9+ 可以直接用内置类型
def process(items: list[int]) -> dict[str, int]: ...
def find(id: int) -> Optional[User]: ...   # 对应 User | null
def parse(value: str | int) -> Any: ...     # Python 3.10+ 联合类型

6.3 静态检查工具

对应 TS 的 tsc --noEmit：

pip install mypy
mypy script.py    # 静态类型检查

IDE（VS Code + Pylance）也会实时提示类型错误。

6.4 关键差异

TS Python
编译期强制类型检查 运行时不检查，靠 mypy/pyright
类型完全擦除 类型注解保留在 __annotations__ 中（反射可用）
interface 无，用 ABC 或 Protocol（结构化子类型）
泛型 <T> Generic[T] 或 list[T]
unknown Any（但 Any 会跳过所有检查，比 unknown 宽松）

7. 模块与包（对应 ES Modules）

7.1 导入

import math                  # 对应 import * as math from 'math'
math.sqrt(16)

from math import sqrt, pi    # 对应 import { sqrt, pi } from 'math'
from math import *           # 对应 import *，不推荐（命名冲突）
from math import sqrt as s   # 对应 import { sqrt as s }

7.2 模块搜索路径

Python 按 sys.path 查找模块，包括：当前目录、标准库、第三方包（site-packages）。对应 Node 的 node_modules 查找。

7.3 包（对应目录模块）

目录下有 __init__.py 即为包（Python 3.3+ 可不写，但推荐写）：

mypackage/
  __init__.py
  module_a.py
  module_b.py

from mypackage import module_a

7.4 if __name__ == "__main__"

if __name__ == "__main__":
    print("直接运行时执行")

对应 Node 中判断 require.main === module，用于"被导入时不执行，直接运行时执行"。

8. 异步编程（asyncio vs Promise）

8.1 基本写法

import asyncio

async def fetch_data():       # 对应 async function
    await asyncio.sleep(1)    # 对应 await delay(1000)
    return "data"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())           # 入口，对应 top-level await 或 IIFE

8.2 并发执行（对应 Promise.all）

async def main():
    results = await asyncio.gather(
        fetch_data(),
        fetch_data(),
        fetch_data()
    )
    # 对应 Promise.all([...])

asyncio.gather 按传入顺序返回结果列表，一个失败默认整体失败，可设 return_exceptions=True 收集异常。

8.3 关键差异

TS (Promise) Python (asyncio)
Promise 创建即执行 协程函数调用返回协程对象，不执行，需 await 或创建 Task
Promise.all asyncio.gather
Promise.race asyncio.wait(return_when=FIRST_COMPLETED)
setTimeout asyncio.sleep
事件循环由 Node 管理 需手动 asyncio.run() 或获取事件循环
可在顶层 await（ES2022） 顶层不能直接 await，需包在 asyncio.run()

坑：在 async 函数里调用同步阻塞函数（如 time.sleep、requests.get）会卡住整个事件循环，必须用异步版本（asyncio.sleep、aiohttp）或 await asyncio.to_thread(...)。

9. 错误处理

9.1 try-except（对应 try-catch）

try:
    result = 10 / 0
except ZeroDivisionError as e:   # 对应 catch (e)，可指定类型
    print(f"错误: {e}")
except (TypeError, ValueError):  # 多个类型
    print("类型或值错误")
else:                            # 没有异常时执行（TS 没有）
    print("成功")
finally:                         # 对应 finally
    print("总是执行")

9.2 抛出异常（对应 throw）

raise ValueError("无效值")

Python 用异常做控制流很常见（如 StopIteration、KeyError），不像 TS 那样尽量避免。

9.3 自定义异常

class AppError(Exception): pass
class NotFoundError(AppError): pass

raise NotFoundError("用户不存在")

推荐继承 Exception，不要继承 BaseException（后者包含 KeyboardInterrupt）。

10. TS 开发者最容易踩的坑

坑 1：缩进错误

没有 {}，缩进错了直接 IndentationError。用 4 空格，不要 Tab。

坑 2：可变默认参数

def append(item, lst=[]):  # 危险！所有调用共享同一个 list
    lst.append(item)

正确：lst=None，函数内创建。

坑 3：is vs ==

a = [1, 2]
b = [1, 2]
a == b   # True（值相等）
a is b   # False（不是同一个对象）

is 对应 === 的"引用相等"，但 Python 小整数（-5~256）和短字符串有缓存，可能 is 也为 True。比较值永远用 ==，比较 None 用 is None。

坑 4：整数除法

7 / 2    # 3.5（真除法，对应 JS 的 /）
7 // 2   # 3（整除，对应 Math.floor）
7 % 2    # 1（取模）

TS 中 / 对整数也是浮点，Python 多了 // 整除。

坑 5：没有块级作用域

for i in range(3):
    pass
print(i)  # 2，循环变量泄漏到外部！

Python 是函数级作用域，循环/条件内的变量外部可见。

坑 6：字典 key 不存在报错

d = {"a": 1}
d["b"]        # KeyError！不是 undefined
d.get("b")    # None，安全
d.get("b", 0) # 0，带默认值

对应 TS 的 obj.b 返回 undefined，Python 直接抛异常。

坑 7：GIL 限制多线程

Python 多线程不能真正并行 CPU 密集任务（GIL），需用多进程。IO 密集任务多线程/协程没问题。

坑 8：布尔值首字母大写

True / False / None，不是 true/false/null。

坑 9：字符串不可变

s = "hello"
s[0] = "H"   # TypeError！字符串不可变
s = "H" + s[1:]  # 正确

坑 10：len() 是内置函数，不是方法

len([1,2,3])   # 正确
[1,2,3].len()  # 错误！没有 .length 属性

12. 学习路径建议

  1. 第 1 周：过一遍本教程，用 Python 重写一个你熟悉的 TS 小工具（如文件处理、API 调用）；
  2. 第 2 周：学 pytest 写测试，学 requests/FastAPI 写接口，适应动态类型；
  3. 第 3 周：学 asyncio 异步编程，理解事件循环和 GIL；
  4. 持续：读 PEP 8（Python 代码风格），用 black + mypy 保持代码质量；
  5. 进阶：学装饰器、生成器、上下文管理器、描述符等 Pythonic 特性。

核心心态：从 TS 到 Python，最大的转变不是语法，而是从"编译器帮我抓错"到"测试和运行时帮我抓错"。拥抱动态类型的灵活性，同时用 type hints + mypy 保留类型安全的好处。

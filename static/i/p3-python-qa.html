Python

Python 基础

1. 什么是 Python？

答案： Python 是一种高级、解释型、通用的编程语言，以简洁易读、生态丰富和强大的社区支持著称。

2. Python 是解释型语言还是编译型语言？

答案： Python 是解释型语言，源代码首先被编译为字节码，然后由 Python 虚拟机（PVM）解释执行。

3. Python 的 GIL 是什么？

答案： GIL 是全局解释器锁，用于保证同一时刻只有一个线程执行 Python 字节码，因此多线程无法充分利用多核 CPU。

4. 什么是 Python 的浅拷贝和深拷贝？

答案： 浅拷贝只复制对象本身，嵌套对象引用同一内存；深拷贝递归复制所有嵌套对象，生成完全独立的新对象。

5. is 和 == 有什么区别？

答案： == 比较值是否相等，is 比较对象在内存中的身份标识是否相同。

6. Python 中可变类型和不可变类型有哪些？

答案： 可变类型：list、dict、set；不可变类型：int、float、str、tuple、bool、frozenset。

7. 列表和元组的区别是什么？

答案： 列表可变，支持增删改；元组不可变，性能更高，常用作不可修改的数据容器。

8. 什么是列表推导式？

答案： 列表推导式是简洁创建列表的语法，例如 [x*2 for x in range(10) if x % 2 == 0]。

9. *args 和 **kwargs 的作用是什么？

答案： *args 用于接收可变数量的位置参数，**kwargs 用于接收可变数量的关键字参数。

10. 什么是 Python 的装饰器？

答案： 装饰器是一种高阶函数，用于在不修改原函数代码的前提下，扩展函数的功能。

11. 什么是 Lambda 表达式？

答案： Lambda 表达式是匿名函数，语法为 lambda x: x + 1，适用于简单的临时函数场景。

12. Python 中如何实现闭包？

答案： 闭包是指内部函数引用了外部函数的变量，并且外部函数返回了内部函数，内部函数保留对外部变量的引用。

13. map()、filter() 和 reduce() 有什么区别？

答案： map() 对可迭代对象每个元素执行函数，filter() 按条件过滤，reduce() 对序列累积计算。

14. 什么是 Python 的迭代器和生成器？

答案： 迭代器实现 iter 和 next 方法；生成器使用 yield 关键字，可惰性生成值，节省内存。

15. yield 和 return 的区别是什么？

答案： return 一次性返回结果并结束函数；yield 会暂停函数，保留状态，可多次返回结果。

16. 什么是生成器表达式？

答案： 生成器表达式与列表推导式类似，但使用圆括号，返回生成器对象，例如 (x*2 for x in range(10))。

17. Python 中 init 和 new 有什么区别？

答案： new 负责创建实例，init 负责初始化实例属性，通常 init 更常用。

18. 什么是 Python 的魔术方法？

答案： 魔术方法是以双下划线开头和结尾的方法，如 str、repr、add，用于自定义对象行为。

19. str 和 repr 的区别是什么？

答案： str 面向用户，返回可读字符串；repr 面向开发者，返回可重新创建对象的无歧义字符串。

20. 什么是 Python 的面向对象编程三大特性？

答案： 封装、继承、多态。Python 支持多继承，通过 super() 调用父类方法。

Python 进阶

21. 什么是 Python 的 MRO？

答案： MRO 是方法解析顺序，Python 使用 C3 线性化算法确定多继承中方法的查找顺序。

22. 什么是描述符（Descriptor）？

答案： 描述符是实现了 get、set 或 delete 方法的类，用于控制属性访问。

23. @property 装饰器的作用是什么？

答案： @property 可以将方法转换为属性访问，实现 getter、setter 和 deleter 的封装。

24. 什么是 Python 的元类（Metaclass）？

答案： 元类是创建类的类，默认是 type。通过自定义元类可以控制类的创建过程。

25. 什么是 Python 的鸭子类型？

答案： 鸭子类型指不关注对象类型，只关注对象是否具有所需的方法或属性，即“如果它像鸭子一样叫，那它就是鸭子”。

26. Python 中的 try...except...finally 如何使用？

答案： try 捕获异常，except 处理异常类型，finally 无论是否异常都会执行，常用于资源释放。

27. 什么是上下文管理器（Context Manager）？

答案： 上下文管理器用于自动管理资源，使用 with 语句，典型实现是 enter 和 exit。

28. with open() 的原理是什么？

答案： with open() 调用文件的 enter 打开文件，exit 关闭文件，确保资源释放。

29. 什么是 Python 的 zip() 函数？

答案： zip() 将多个可迭代对象的元素按位置打包成元组，返回迭代器，长度以最短序列为准。

30. 如何合并两个字典？

答案： Python 3.9+ 支持 dict1 | dict2，旧版本可用 {dict1, dict2} 或 dict1.update(dict2)。

31. Python 中如何排序？

答案： 列表使用 sort() 或 sorted()，可通过 key 参数指定排序规则，如 sorted(list, key=lambda x: x['age'])。

32. 什么是 Python 的 enumerate()？

答案： enumerate() 用于同时获取索引和值，例如 for i, v in enumerate(list):。

33. 什么是 Python 的 defaultdict？

答案： defaultdict 是 collections 模块提供的字典，访问不存在的键时会自动返回默认值。

34. 什么是 Python 的 Counter？

答案： Counter 是 collections 模块提供的计数器，用于快速统计可哈希对象的出现次数。

35. deque 和列表有什么区别？

答案： deque 是双端队列，两端插入和删除的时间复杂度为 O(1)，列表尾部插入 O(1)、头部插入 O(n)。

Python 高级与工程

36. 什么是 Python 的内存管理？

答案： Python 使用引用计数和垃圾回收机制管理内存，循环引用由分代垃圾回收器处理。

37. 什么是 Python 的 slots？

答案： slots 用于限制类实例可拥有的属性，减少内存占用并加速属性访问。

38. 什么是 Python 的反射和自省？

答案： 自省是运行时检查对象类型的能力，如 type()、dir()、hasattr()、getattr()；反射是动态调用或修改对象成员。

39. 什么是 Python 的 monkey patch？

答案： Monkey patch 指在运行时动态修改模块、类或函数的行为，常用于测试和临时修复。

40. 如何实现 Python 单例模式？

答案： 可通过重写 new 方法、使用元类或装饰器实现，确保类只有一个实例。

41. Python 中多线程和多进程如何选择？

答案： CPU 密集型任务用多进程绕过 GIL；IO 密集型任务用多线程或协程提高效率。

42. 什么是 Python 的 asyncio 和协程？

答案： asyncio 是异步 IO 库，协程使用 async 和 await 关键字实现非阻塞并发。

43. async 和 await 的作用是什么？

答案： async 定义异步函数，await 挂起当前协程等待异步操作完成，不阻塞事件循环。

44. 什么是 Python 的虚拟环境？

答案： 虚拟环境是隔离的 Python 运行环境，用于管理不同项目的依赖，避免版本冲突。

45. 如何管理 Python 依赖？

答案： 使用 requirements.txt 或 pyproject.toml，通过 pip 安装，工具可选 venv、poetry、pipenv。

46. 什么是 Python 的 WSGI 和 ASGI？

答案： WSGI 是同步 Web 服务器网关接口，ASGI 支持异步通信，是现代异步框架（如 FastAPI）的基础。

47. 什么是 Python 的 Gunicorn 和 Uvicorn？

答案： Gunicorn 是 WSGI HTTP 服务器，Uvicorn 是 ASGI 服务器，常与 FastAPI 配合使用。

48. Python 中如何进行单元测试？

答案： 使用 unittest 或 pytest 编写测试用例，通过断言验证函数行为和输出。

49. 什么是 Python 的 Pytest fixture？

答案： Fixture 是 pytest 的测试前置和后置处理机制，用于准备测试环境、共享测试数据。

50. 什么是 Python 的 PEP 8？

答案： PEP 8 是 Python 代码风格指南，涵盖命名规范、缩进、行长、导入顺序等，旨在提高代码可读性。

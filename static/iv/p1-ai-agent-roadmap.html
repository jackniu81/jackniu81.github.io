AI Agent 学习路线

P1 重要进阶 ← 返回目录

﻿# 普通开发者如何成为 AI Agent 工程师

写给有编程基础但想转型 AI Agent 方向的开发者。不需要数学博士，不需要从头训练模型，只需要按步骤系统学习。

一、自我评估：你现在在哪里？

在开始之前，先对号入座：

类型 描述 起点建议
前端/全栈开发者 熟悉 JS/TS，有 API 调用经验 从第二阶段开始，Python 补充学习
后端开发者（Java/C#/Go） 有系统设计经验，Python 较弱 补 Python 后从第二阶段开始
Python 开发者 熟悉 Python，有 API 开发经验 直接从第二阶段开始
数据工程师 熟悉 Python、SQL 直接从第二阶段开始，重点补 LLM 部分

二、学习路线总览

第一阶段：夯实基础（2-4 周）
    └── Python 基础 + HTTP API 调用

第二阶段：LLM 核心能力（3-4 周）
    └── LLM API 使用 + Prompt Engineering + RAG

第三阶段：Agent 开发（4-6 周）
    └── 工具调用 + LangChain/LangGraph + 构建第一个 Agent

第四阶段：工程化（3-4 周）
    └── 多 Agent + 评估 + 部署 + 监控

第五阶段：持续进阶（长期）
    └── 前沿论文 + 开源贡献 + 实战项目

三、第一阶段：夯实基础

如果你已经熟悉 Python 和 HTTP，可以跳过此阶段。

1.1 Python 核心语法

重点掌握：
- 数据类型（list、dict、set、tuple）
- 函数、装饰器、lambda、闭包
- 类与面向对象（继承、魔术方法）
- 异常处理（try/except）
- 文件读写、JSON 解析
- 异步编程（asyncio / async await） ← Agent 开发必须掌握

学习资源：
- 文档：Python 官方文档
- 课程：廖雪峰 Python 教程（中文，免费）
- 练习：LeetCode Python 题目（Easy 级别热身）

掌握标准： 能独立写一个读取 JSON 文件、调用 REST API、将结果写入数据库的 Python 脚本。

1.2 HTTP & REST API 基础

重点掌握：
- HTTP 方法（GET、POST、PUT、DELETE）
- 请求头（Headers）、请求体（Body）、状态码
- JSON 数据格式
- Python 的 requests 库和 httpx（支持异步）

示例代码：

import httpx

async def call_api():
    async with httpx.AsyncClient() as client:
        response = await client.post(
            "https://api.example.com/chat",
            headers={"Authorization": "Bearer YOUR_KEY"},
            json={"message": "Hello"}
        )
        return response.json()

2.2 LLM API 调用

主流 API 提供商：
- OpenAI：GPT-4o，最成熟的生态
- Anthropic：Claude 3.5/3.7，推理能力强，支持 Computer Use
- Google：Gemini 1.5 Pro，超长上下文（100万 Token）
- 国内：通义千问（阿里）、文心一言（百度）、智谱 ChatGLM

快速上手（OpenAI SDK）：

from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是一个专业的助手"},
        {"role": "user", "content": "解释一下什么是 AI Agent"}
    ]
)

print(response.choices[0].message.content)

2.3 Prompt Engineering（提示词工程）

核心技巧：

技巧 说明 示例
角色设定 告诉 LLM 它是谁 "你是一个资深 Python 工程师"
Few-shot 给出输入/输出示例 "示例：输入 A，输出 B"
Chain-of-Thought 让模型一步步思考 "请一步步分析..."
结构化输出 要求 JSON 格式 "以 JSON 格式返回，包含字段 name, score"
约束条件 明确不能做什么 "不要超过 200 字，不要使用专业术语"

学习资源：
- Anthropic Prompt Engineering 指南（中文，强烈推荐）
- OpenAI Prompt Engineering 最佳实践
- Learn Prompting（中文开源教程）

2.4 RAG（检索增强生成）

核心流程：

1. 文档预处理
   ├── 加载文档（PDF/Word/网页）
   ├── 文本分块（Chunk）
   └── 向量化（Embedding）→ 存入向量数据库

2. 查询流程
   ├── 用户提问 → 向量化
   ├── 向量数据库相似度检索
   └── 相关文档 + 用户问题 → LLM 生成回答

动手实践（使用 LangChain + Chroma）：

from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings

# 加载 PDF
loader = PyPDFLoader("document.pdf")
docs = loader.load()

# 分块
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

# 向量化并存储
vectorstore = Chroma.from_documents(chunks, OpenAIEmbeddings())

# 检索
results = vectorstore.similarity_search("什么是 AI Agent？", k=3)

五、第三阶段：Agent 开发

3.1 Function Calling / Tool Use

这是 Agent 的核心能力。 学会让 LLM 决定调用什么工具。

import json
from openai import OpenAI

client = OpenAI()

# 定义工具
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "获取指定城市的当前天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名，如北京"}
            },
            "required": ["city"]
        }
    }
}]

# 实际工具函数
def get_weather(city: str) -> str:
    return f"{city}：晴天，25°C"

# 调用模型
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "北京今天天气怎么样？"}],
    tools=tools
)

# 处理工具调用
if response.choices[0].message.tool_calls:
    tool_call = response.choices[0].message.tool_calls[0]
    args = json.loads(tool_call.function.arguments)
    result = get_weather(**args)
    print(result)

3.2 LangChain 入门

安装：

pip install langchain langchain-openai langchain-community

构建第一个 Agent：

from langchain_openai import ChatOpenAI
from langchain.agents import create_react_agent, AgentExecutor
from langchain.tools import tool
from langchain import hub

@tool
def calculate(expression: str) -> str:
    """计算数学表达式，如 '2 + 3 * 4'"""
    return str(eval(expression))

@tool
def search_web(query: str) -> str:
    """搜索网络获取信息"""
    return f"搜索 '{query}' 的结果：这是模拟结果"

llm = ChatOpenAI(model="gpt-4o")
tools = [calculate, search_web]
prompt = hub.pull("hwchase17/react")

agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

result = executor.invoke({"input": "计算 (10 + 5) * 3 的结果"})
print(result["output"])

3.3 LangGraph 进阶

适合复杂工作流，支持循环和条件分支：

from langgraph.graph import StateGraph, END
from typing import TypedDict

class AgentState(TypedDict):
    messages: list
    next_step: str

def planner(state: AgentState):
    # 规划下一步
    return {"next_step": "executor"}

def executor(state: AgentState):
    # 执行任务
    return {"next_step": "reviewer"}

def reviewer(state: AgentState):
    # 检查结果
    return {"next_step": END}

# 构建图
graph = StateGraph(AgentState)
graph.add_node("planner", planner)
graph.add_node("executor", executor)
graph.add_node("reviewer", reviewer)

graph.set_entry_point("planner")
graph.add_edge("planner", "executor")
graph.add_edge("executor", "reviewer")

app = graph.compile()

六、第四阶段：工程化能力

4.1 Agent 监控与调试

LangSmith（LangChain 官方调试平台）：

import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "YOUR_LANGSMITH_KEY"

启用后，所有 Agent 的每一步调用都会被记录，可在 Web 界面查看。

  • LangSmith 官网

4.2 流式输出（Streaming）

from openai import OpenAI

client = OpenAI()

with client.chat.completions.stream(
    model="gpt-4o",
    messages=[{"role": "user", "content": "写一首关于 AI 的诗"}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

4.3 部署 Agent 服务

快速部署 API（使用 FastAPI）：

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class ChatRequest(BaseModel):
    message: str

@app.post("/chat")
async def chat(request: ChatRequest):
    # 调用你的 Agent
    result = await your_agent.run(request.message)
    return {"response": result}

# 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000

4.4 成本控制

  • 选择合适的模型：简单任务用 GPT-4o-mini / Claude Haiku，复杂任务再用强模型
  • 限制 context 长度：压缩历史消息，只保留最近 N 轮
  • 缓存重复请求：相同 prompt 使用 Redis 缓存结果
  • 监控 Token 消耗：记录每次调用的 Token 数量和费用

八、常见误区

  • 不需要从头训练模型：99% 的 Agent 工程工作是调用 API + 工程化，不是训练模型
  • 不要一开始就学框架：先理解 LLM API 调用，再学 LangChain，否则不理解底层
  • 不要追求完美 Prompt：工程化地评估、迭代才是正确路径
  • 不要忽视成本：开发时注意 Token 消耗，养成监控习惯
  • 不要只看教程：动手做项目才是最快的学习方式

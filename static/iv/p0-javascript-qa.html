JavaScript

基础语法与类型

1. JavaScript 是什么？

答案： JavaScript 是一门高阶、动态、解释型编程语言，广泛用于 Web 前端，也可用于服务端和脚本开发。

2. JavaScript 的基本数据类型有哪些？

答案： 常见基本类型有 string、number、boolean、undefined、null、symbol 和 bigint。

3. typeof null 为什么是 object？

答案： 这是 JavaScript 早期实现遗留问题，并不是因为 null 真正属于对象类型。

4. undefined 和 null 的区别是什么？

答案： undefined 常表示未赋值，null 常表示主动置空，两者语义不同。

5. 什么是引用类型？

答案： 对象、数组、函数等存储的是引用地址，多个变量可能指向同一块内存。

6. == 和 === 的区别是什么？

答案： == 会做隐式类型转换后再比较，=== 不会转换类型，要求类型和值都相等。

7. 为什么推荐使用 ===？

答案： 因为它能避免隐式类型转换带来的歧义，让比较结果更可预测。

8. NaN 有什么特点？

答案： NaN 表示“不是一个数字”，它与任何值都不相等，包括它自己。

9. 如何判断一个值是不是 NaN？

答案： 推荐使用 Number.isNaN()，因为它不会做不必要的类型转换。

10. let、const、var 的区别是什么？

答案： var 有变量提升且是函数作用域；let 和 const 是块级作用域，const 不能重新赋值。

11. 什么是变量提升？

答案： 变量提升指声明会在编译阶段提前处理，但赋值不会一起提升。

12. 什么是暂时性死区？

答案： 在 let 和 const 声明前访问变量会报错，这段区域就叫暂时性死区。

13. const 声明的对象为什么还能改属性？

答案： 因为 const 只保证变量绑定地址不变，不保证对象内部内容不可变。

14. 什么是类型转换？

答案： 类型转换是把一个值转换成另一种类型，分为显式转换和隐式转换。

15. 显式转换常见方式有哪些？

答案： 常见有 Number()、String()、Boolean()、parseInt() 和 parseFloat()。

16. 哪些值会被转换成 false？

答案： 常见有 false、0、-0、''、null、undefined 和 NaN。

17. 什么是模板字符串？

答案： 模板字符串使用反引号包裹，支持多行字符串和 ${} 插值表达式。

18. 什么是解构赋值？

答案： 解构赋值允许从数组或对象中快速提取值并赋给变量。

19. 展开运算符有什么作用？

答案： 展开运算符可用于展开数组、对象或函数参数，常用于拷贝和合并数据。

20. 剩余参数是什么？

答案： 剩余参数用 ...args 接收不定数量参数，并将其收集为数组。

作用域、闭包与 this

21. 什么是作用域？

答案： 作用域是变量和函数可被访问的范围，常见有全局作用域、函数作用域和块级作用域。

22. 什么是作用域链？

答案： 当访问变量时，JavaScript 会沿当前作用域逐级向外查找，形成作用域链。

23. 什么是闭包？

答案： 闭包是函数和其词法作用域的组合，即使函数在外部执行，也能访问定义时的外部变量。

关键特性：

  • 函数嵌套：内部函数引用外部函数的变量
  • 变量持久化：外部函数执行完毕后，变量不会销毁
  • 私有数据：外部无法直接访问闭包内的变量

潜在问题：

  1. 内存占用：闭包会阻止垃圾回收，如果创建大量闭包且不释放，可能导致内存泄漏。
  2. 过期变量：在异步场景中可能读取到旧的值（经典的 for 循环 setTimeout 问题）。

实际应用：

  • 工厂函数（createCounter）
  • 防抖/节流（保存 timer 引用）
  • 模块模式（暴露公共 API，隐藏私有变量）

24. 闭包的常见应用场景有哪些？

答案： 常见于函数工厂、模块封装、回调保留上下文和防抖节流实现。

25. 闭包可能带来什么问题？

答案： 如果不合理使用，可能导致内存占用增加或读取到过期变量值。

26. 什么是 this？

答案： this 是函数执行时的上下文对象，它的指向取决于调用方式而不是定义位置。

27. 普通函数中的 this 如何确定？

答案： 默认调用时在严格模式下是 undefined，作为对象方法调用时通常指向该对象。

28. 箭头函数的 this 有什么特点？

答案： 箭头函数没有自己的 this，它会继承外层词法作用域的 this。

29. call、apply、bind 的区别是什么？

答案： 它们都可改变函数 this；call 和 apply 立即执行，bind 返回新函数延后执行。

30. 什么情况下适合用箭头函数？

答案： 适合不需要自身 this、arguments、new 的回调场景。

原型与继承

31. 什么是原型？

答案： 原型是对象用于共享属性和方法的一套机制，大多数对象都可通过原型链访问继承内容。

32. 什么是原型链？

答案： 对象查找属性时如果自身没有，会沿着原型不断向上查找，直到 null 为止，这就是原型链。

33. prototype 和 __proto__ 的区别是什么？

答案： prototype 是函数在作为构造函数时提供给实例共享的方法对象；__proto__ 是对象指向其原型的内部链接。

34. 什么是构造函数？

答案： 构造函数是通过 new 调用来创建对象的函数，通常用于初始化实例属性。

35. new 操作符做了什么？

答案： 它创建新对象、链接原型、绑定 this、执行构造函数并返回新对象。

36. 什么是继承？

答案： 继承是让一个对象或类复用另一个对象或类能力的机制。

37. ES6 class 本质上是什么？

答案： class 本质上是原型继承的语法糖，并没有改变 JavaScript 原型机制。

38. extends 的作用是什么？

答案： extends 用于类继承，子类可以复用父类属性和方法。

39. super 的作用是什么？

答案： super 用于调用父类构造函数或父类方法。

40. 为什么说 JavaScript 是基于原型的语言？

答案： 因为对象之间的能力复用主要依赖原型链，而不是传统类继承体系。

异步编程

41. 什么是同步和异步？

答案： 同步任务按顺序阻塞执行；异步任务可先挂起，等条件满足后再继续处理。

42. 什么是回调函数？

答案： 回调函数是作为参数传给其他函数，并在特定时机执行的函数。

43. 什么是回调地狱？

答案： 指多层嵌套回调导致代码难读、难维护、难处理错误的情况。

44. Promise 是什么？

答案： Promise 是对异步结果的抽象，表示一个未来可能成功或失败的操作。

45. Promise 有哪些状态？

答案： 有 pending、fulfilled 和 rejected 三种状态。

46. then、catch、finally 分别做什么？

答案： then 处理成功结果，catch 处理失败，finally 无论结果如何都会执行。

47. async/await 是什么？

答案： 它是基于 Promise 的异步语法糖，让异步代码写起来更像同步流程。

48. await 后面必须是什么？

答案： 通常是 Promise，也可以是普通值；普通值会被自动包装为已完成状态。

49. async 函数的返回值是什么？

答案： async 函数总是返回一个 Promise。

50. 如何并发执行多个异步任务？

答案： 可以使用 Promise.all() 或 Promise.allSettled() 并发处理多个 Promise。

51. Promise.all 和 Promise.allSettled 的区别是什么？

答案： 前者任一失败就整体失败；后者会返回每个任务的最终状态。

52. 什么是事件循环？

答案： 事件循环是 JavaScript 实现异步编程的核心机制，负责协调同步代码、微任务和宏任务的执行顺序。由于 JavaScript 是单线程的，事件循环让 JS 能处理异步操作而不阻塞主线程。

详细步骤

  1. 执行同步代码：从全局上下文开始，所有同步代码进入调用栈执行
  2. 清空微任务队列：调用栈清空后，检查微任务队列，循环执行直到队列完全为空
  3. 执行渲染：如果需要更新UI，浏览器会执行渲染
  4. 执行宏任务：从宏任务队列取出一个任务执行
  5. 重复：回到步骤1，形成循环

为什么这样设计？

  1. 单线程不阻塞：异步操作通过队列管理，主线程持续执行
  2. 微任务优先：保证 Promise 回调和 DOM 更新的顺序性
  3. 渲染时机：微任务清空后渲染，确保UI一致性
  4. 任务调度：宏任务按时间顺序排队执行

事件循环通过同步 → 微任务 → 渲染 → 宏任务的循环，让 JavaScript 单线程能够高效处理异步操作，同时保证代码执行顺序和UI响应性。

53. 什么是宏任务？

答案： 常见宏任务包括 setTimeout、setInterval、I/O、等。

54. 什么是微任务？

答案： 常见微任务包括 Promise.then、catch、finally、queueMicrotask。

55. 为什么微任务优先于宏任务？

答案： 事件循环会在当前宏任务结束后，先清空微任务队列，再进入下一个宏任务。

数组、对象与函数

56. 常见数组遍历方法有哪些？

答案： 常见有 forEach、map、filter、reduce、some、every、find 等。

57. map 和 forEach 的区别是什么？

答案： map 会返回新数组，适合做数据映射；forEach 主要用于遍历副作用操作。

58. filter 的作用是什么？

答案： filter 根据条件筛选数组项，并返回一个新数组。

59. reduce 常用于什么？

答案： 常用于聚合计算、数组扁平化、对象构建和函数组合等场景。

60. 如何判断一个变量是不是数组？

答案： 推荐使用 Array.isArray()。

61. 深拷贝和浅拷贝的区别是什么？

答案： 浅拷贝只复制第一层引用，深拷贝会递归复制嵌套对象，生成完全独立的新结构。

62. 常见浅拷贝方式有哪些？

答案： 常见有展开运算符、Object.assign()、数组的 slice() 等。

63. JSON.parse(JSON.stringify()) 做深拷贝有什么问题？

答案： 它会丢失函数、undefined、symbol、循环引用和特殊对象类型信息。

64. 什么是高阶函数？

答案： 高阶函数是接收函数作为参数或返回函数的函数。

65. 什么是柯里化？

答案： 柯里化是把接收多个参数的函数拆成一系列接收单个参数函数的技术。

66. 什么是函数防抖？

答案： 防抖是高频触发时只在停止触发一段时间后执行一次。

67. 什么是函数节流？

答案： 节流是规定时间内最多执行一次，适合滚动和窗口缩放等场景。

68. 什么是纯函数？

答案： 纯函数对于相同输入始终返回相同输出，且没有副作用。

69. 为什么纯函数更容易维护？

答案： 因为它结果可预测、易测试、易复用，也更利于性能优化。

70. 什么是副作用？

答案： 副作用是函数执行过程中对外部状态产生影响，如修改全局变量、请求接口、操作 DOM 等。

DOM、浏览器与 Web API

71. DOM 是什么？

答案： DOM 是浏览器对 HTML 文档的对象化表示，JavaScript 可以通过它读写页面结构。

72. BOM 是什么？

答案： BOM 是浏览器对象模型，提供 window、location、history、navigator 等浏览器能力。

73. 事件冒泡是什么？

答案： 事件冒泡是事件从目标元素逐层向父级传播的过程。

74. 事件捕获是什么？

答案： 事件捕获是事件从最外层祖先节点向目标节点传播的过程。

75. 如何阻止事件冒泡？

答案： 可以使用 event.stopPropagation()。

76. 如何阻止默认行为？

答案： 可以使用 event.preventDefault()。

77. 什么是事件委托？

答案： 事件委托是把子元素事件统一绑定到父元素上，利用事件冒泡处理，提高性能和动态节点支持能力。

78. localStorage 和 sessionStorage 的区别是什么？

答案： localStorage 持久保存，除非手动清除；sessionStorage 在会话结束后清空。

79. Cookie、localStorage、sessionStorage 的区别是什么？

答案： Cookie 会随请求发送，容量较小；localStorage 和 sessionStorage 只在浏览器端保存，容量通常更大。

80. 什么是同源策略？

答案： 同源策略限制不同源之间的资源访问，用于保障浏览器安全。

81. 什么是跨域？

答案： 当协议、域名或端口任一不同，就属于跨域访问。

82. 常见跨域解决方案有哪些？

答案： 常见有 CORS、反向代理、JSONP（仅限 GET）等。

83. 什么是 AJAX？

答案： AJAX 是在不刷新页面的情况下与服务器交换数据并更新页面内容的技术方式。

84. 什么是防抖在输入搜索中的应用？

答案： 它可避免用户每输入一个字符就发请求，从而减少无效调用。

85. 什么是节流在滚动中的应用？

答案： 它可避免滚动事件高频触发导致频繁计算和渲染。

模块化、面向对象与工程化

86. 什么是模块化？

答案： 模块化是把代码拆成职责清晰、可复用、可维护的独立单元。

87. CommonJS 和 ES Module 的区别是什么？

答案： CommonJS 主要用于 Node.js，运行时加载；ES Module 是官方标准，支持静态分析和浏览器原生支持。

88. import 和 require 的区别是什么？

答案： import 属于 ES Module，通常在编译时处理；require 是 CommonJS 的同步加载方式。

89. 什么是默认导出和命名导出？

答案： 默认导出每个模块只能有一个；命名导出可以有多个，并通过名称导入。

90. 什么是严格模式？

答案： 严格模式通过 'use strict' 开启，可让 JavaScript 执行更严格，减少隐式错误。

91. 什么是垃圾回收？

答案： 垃圾回收是 JavaScript 引擎自动释放不再可访问内存的机制。

92. 常见垃圾回收策略有哪些？

答案： 常见有标记清除和引用计数，现代引擎主要以标记清除为主。

93. 什么是内存泄漏？

答案： 内存泄漏是指本该释放的内存因为仍被引用而无法回收，导致占用持续增加。

94. 常见内存泄漏场景有哪些？

答案： 常见有未清理定时器、事件监听未移除、闭包滥用和全局变量污染。

95. 什么是函数式编程思想？

答案： 它强调不可变数据、纯函数、函数组合和声明式处理。

96. 什么是面向对象思想？

答案： 面向对象强调通过对象封装数据与行为，并通过继承、多态等方式组织代码。

97. JavaScript 中如何实现封装？

答案： 可以通过闭包、模块、类和私有字段等方式实现封装。

99. JavaScript 为什么是前端核心语言？

答案： 因为它直接运行在浏览器中，承担交互、逻辑、网络请求和应用工程化等核心职责。

100. 如何总结 JavaScript 的核心能力？

答案： JavaScript 的核心能力可以概括为：动态类型、函数式特性、原型继承、异步编程和强大的浏览器生态支持。

进阶特性

101. for...in 和 for...of 的区别是什么？

答案： for...in 遍历对象的可枚举属性键（包括继承的原型链属性），主要用于普通对象；for...of 遍历实现了 Symbol.iterator 的可迭代对象的值，适合数组、字符串、Set、Map 等，不适用于普通对象。遍历数组建议用 for...of 或 forEach，遍历对象用 for...in 并配合 hasOwnProperty 过滤继承属性。

102. typeof 和 instanceof 的区别是什么？

答案： typeof 返回字符串表示基本类型，对 null 返回 "object"（历史遗留问题），对函数返回 "function"，适合判断基本类型；instanceof 检查对象是否在某构造函数的原型链上，只适用于引用类型，不适合跨 iframe 场景。判断数组推荐 Array.isArray()，判断精确类型可用 Object.prototype.toString.call()。

103. ?. 可选链 和 ?? 空值合并运算符分别有什么作用？

答案： ?. 可选链在访问深层属性时，若某层为 null 或 undefined 则短路返回 undefined，避免报错，如 obj?.a?.b；?? 空值合并只在左侧为 null 或 undefined 时返回右侧默认值，与 || 的区别是不把 0、''、false 视为无效值。组合用法 obj?.value ?? 'default' 是常见安全访问模式。

104. 什么是 WeakMap 和 WeakSet？

答案： WeakMap 的键必须是对象，且持有弱引用，不会阻止垃圾回收；WeakSet 只存放对象弱引用。它们都不可遍历、没有 size 属性。常用于存储与对象关联的私有数据（如 DOM 节点元数据）或缓存，避免内存泄漏。

105. 什么是 Generator 函数？

答案： Generator 是可暂停执行的函数，用 function* 声明，通过 yield 输出值并暂停，调用时返回一个迭代器对象。每次调用 .next() 执行到下一个 yield 处，.next(value) 还可以向 yield 传回值。适合实现惰性序列、分步执行流程，也是 async/await 的底层原理基础。

106. 什么是 Proxy 和 Reflect？

答案： Proxy 可拦截并自定义对象的基本操作（如读写属性、函数调用、in 操作符等），是 Vue 3 响应式系统的核心基础。Reflect 提供与 Proxy 捕获器一一对应的静态方法，在 handler 中调用 Reflect 方法可以保持对象的默认行为，二者通常配合使用。

107. 什么是 Symbol？

答案： Symbol 是 ES6 引入的原始类型，每次调用 Symbol() 产生唯一值。常见用途：定义对象唯一键避免属性名冲突、实现迭代协议（Symbol.iterator）、自定义 toString 行为（Symbol.toPrimitive）等。Symbol 属性默认不出现在 for...in、Object.keys() 和 JSON.stringify() 中。

108. Object.freeze 和 const 的区别是什么？

答案： const 只保证变量绑定不可重新赋值，对象内容仍可修改；Object.freeze 让对象属性不可修改、不可添加或删除，但只是浅冻结，嵌套对象属性仍可变。深度冻结需要递归对每层对象调用 freeze。两者解决的是不同层面的不可变问题。

109. Promise.race 和 Promise.any 的区别是什么？

答案： Promise.race 返回最先敲定（无论成功或失败）的 Promise 结果；Promise.any 返回最先成功的 Promise，只有全部 reject 才会以 AggregateError 拒绝。race 适合超时控制（竞争一个 timeout Promise），any 适合多源竞速取最快成功的响应。

110. 什么是 Object.keys / Object.values / Object.entries 的区别？

答案： 三者都只返回对象自身的可枚举属性，不含继承属性。Object.keys 返回键数组；Object.values 返回值数组；Object.entries 返回 [key, value] 键值对数组，常配合 for...of 或 fromEntries 做对象转换。

111. 什么是防抖和节流的实现原理？

答案： 防抖（debounce）：每次触发时清除之前的定时器，重新计时，时间到期后才执行。适合搜索输入、窗口 resize 结束后的操作。节流（throttle）：记录上次执行时间，每次触发判断时间差是否超过阈值，超过才执行。适合滚动监听、鼠标移动等高频事件。二者都用闭包保存状态（timer/lastTime）。

112. 什么是模块的循环依赖？如何处理？

答案： 循环依赖指模块 A 依赖 B，B 又依赖 A。ES Module 的循环依赖在加载时会返回未完成的绑定（实时绑定），执行时才有值，可能导致某个值为 undefined。处理方式：重构代码抽出公共依赖为第三个模块、延迟访问（在函数内部引用而非顶层）、检查循环依赖工具（如 madge）。

针对中国国内中小型项目，结合流行程度，推荐以下技术栈：

国内主流技术栈组合

核心框架

  • React 19 - 主流前端框架
  • Vite - 构建工具（国内普及率极高）
  • TypeScript - 类型安全

UI 组件库（国内偏好）

Ant Design - 国内首选

npm install antd @ant-design/icons

国内优势：
- 蚂蚁集团出品，国内认可度高
- 中文文档完善
- 企业级组件丰富
- 国内招聘市场常见

Arco Design - 字节跳动出品

npm install @arco-design/web-react

特点：
- 字节跳动开源
- 现代化设计
- 性能优秀

状态管理

Zustand - 轻量级首选

npm install zustand

国内趋势：
- 简单易学
- 性能优秀
- 社区接受度高

Redux Toolkit - 企业项目

  • 大型项目首选
  • 国内企业使用广泛

样式方案

Tailwind CSS - 现代选择

npm install -D tailwindcss postcss autoprefixer

国内现状：
- 新项目采用率高
- 开发效率高

CSS Modules - 传统稳定

  • CRA 默认支持
  • 学习成本低

数据请求

Axios - 国内绝对主流

npm install axios

国内优势：
- 使用率最高
- 中文教程丰富
- 招聘要求常见

TanStack Query - 现代选择

npm install @tanstack/react-query

路由管理

React Router - 标准选择

npm install react-router-dom

国内招聘市场偏好

高频技术栈

  1. React + Ant Design + Redux
  2. React + Vite + TypeScript
  3. React + Axios + React Router

企业偏好

  • 大厂：Ant Design + Redux Toolkit
  • 中小厂：轻量级组件库 + Zustand

推荐方案

国内中小型项目最佳实践：
- React 19 + Vite + TypeScript
- Ant Design（企业认可度高）
- Zustand（简单高效）
- Axios（国内主流）
- React Router（标准路由）

这个组合在国内招聘市场接受度高，学习资源丰富，适合中小型项目快速开发和维护。

﻿# CSS / HTML5 常见题目 100 道（附答案）

HTML5 基础

1. 什么是 HTML？

答案：
HTML 是超文本标记语言，用于定义网页的结构和语义。

2. 什么是 HTML5？

答案：
HTML5 是 HTML 的现代标准版本，增强了语义化、多媒体、表单和 Web API 能力。

3. 为什么要强调语义化标签？

答案：
语义化有助于提升可读性、可维护性、SEO 和无障碍访问能力。

4. 常见语义化标签有哪些？

答案：
常见有 header、nav、main、section、article、aside、footer 等。

5. div 和语义化标签的区别是什么？

答案：
div 只有结构作用，语义化标签还表达内容含义和页面角色。

6. 什么是块级元素和行内元素？

答案：
块级元素通常独占一行，行内元素通常不会独占一行，只包裹内容本身。

7. img 标签的 alt 属性有什么作用？

答案：
alt 用于图片无法显示时提供替代文本，也有助于无障碍和搜索引擎理解内容。

8. meta viewport 的作用是什么？

答案：
它用于控制移动端页面视口宽度和缩放行为，是响应式布局基础配置之一。

9. defer 和 async 的区别是什么？

答案：
两者都能异步下载脚本；async 下载完立即执行，顺序不可控；defer 会按顺序在 DOM 解析完成后执行。

10. 什么是无障碍访问？

答案：
无障碍访问是让残障用户也能顺畅使用网页，包括语义标签、键盘操作、对比度和屏幕阅读器支持等。

11. HTML5 新增了哪些表单能力？

答案：
新增了更多输入类型、占位符、校验属性和更好的移动端适配能力。

12. 常见 HTML5 输入类型有哪些？

答案：
如 email、number、date、url、tel、range 等。

13. label 标签为什么重要？

答案：
它能提升表单可用性和无障碍体验，点击标签即可聚焦关联控件。

14. canvas 和 svg 的区别是什么？

答案：
canvas 更适合像素级绘制和高频渲染；svg 更适合矢量图形和结构化图形场景。

15. audio 和 video 标签带来了什么？

答案：
它们让网页可以原生嵌入音视频，而不必依赖传统插件。

16. 什么是自定义数据属性？

答案：
自定义数据属性以 data- 开头，可用于在 DOM 上存储扩展信息。

17. localStorage 和 sessionStorage 属于 HTML5 哪类能力？

答案：
它们属于 Web Storage 本地存储能力。

18. 什么是拖拽 API？

答案：
HTML5 提供了拖拽相关事件和数据传递机制，用于实现元素拖放交互。

19. 什么是 Web Worker？

答案：
Web Worker 允许在后台线程执行脚本，避免阻塞主线程 UI。

20. 什么是 WebSocket？

答案：
WebSocket 提供浏览器与服务器之间的全双工长连接通信能力。

CSS 基础

21. CSS 是什么？

答案：
CSS 是层叠样式表，用于控制网页的外观、布局和视觉表现。

22. CSS 的引入方式有哪些？

答案：
常见有行内样式、内部样式表和外部样式表，实际项目中多使用外部样式表。

23. 什么是选择器？

答案：
选择器用于指定样式作用的元素范围，如标签、类、ID 和属性选择器等。

24. 常见选择器有哪些？

答案：
常见有标签选择器、类选择器、ID 选择器、后代选择器、伪类、伪元素等。

25. 什么是伪类？

答案：
伪类用于描述元素的特殊状态，如 :hover、:focus、:nth-child()。
li:nth-child(odd) 奇数行; nth: n-th

26. 什么是伪元素？

答案：
伪元素用于选中元素内容的特殊部分，如 ::before、::after。

27. CSS 优先级如何计算？

答案：
一般比较内联样式、ID、类/属性/伪类、标签/伪元素的权重，权重高者优先。

28. !important 有什么作用？

答案：
它会强行提高声明优先级，但不应滥用，否则会降低样式可维护性。

29. 什么是继承？

答案：
继承指某些样式属性会从父元素传递给子元素，如字体和颜色等。

30. 什么是层叠？

答案：
层叠是指多个样式规则共同作用时，浏览器根据来源、优先级和顺序决定最终结果。

盒模型与布局

31. 什么是盒模型？

答案：
盒模型描述元素由 content、padding、border、margin 组成。

32. 标准盒模型和怪异盒模型的区别是什么？

答案：
标准盒模型中宽高只包含内容区；怪异盒模型中宽高包含内容、内边距和边框。

33. box-sizing: border-box 有什么好处？

答案：
它让元素宽高计算更直观，更适合实际项目布局。

34. 什么是外边距塌陷？

答案：
垂直相邻块级元素的 margin 可能合并为一个更大的外边距，这种现象叫塌陷。

35. 如何解决外边距塌陷？

答案：
可通过创建 BFC、设置边框、内边距或改变布局方式来解决。

36. 什么是 BFC（Block Formatting Context）

答案：
BFC 是块级格式化上下文，可用于隔离布局影响、清除浮动和避免外边距塌陷等。

37. 如何触发 BFC

答案：
常见方式有设置 display: flow-root、 overflow: hidden、float、position: absolute 等。

38. display 常见取值有哪些？

答案：
常见有 block、inline、inline-block、none、flex、grid。

39. position 常见取值有哪些？

答案：
常见有 static、relative、absolute、fixed、sticky。

40. relative 和 absolute 的区别是什么？

答案：
relative 相对自身原位置偏移；absolute 脱离文档流并相对最近定位祖先定位。

41. fixed 的特点是什么？

答案：
fixed 元素相对视口定位，通常不随页面滚动而移动。

42. sticky 是什么？

答案：
sticky 是粘性定位，在达到阈值前表现像普通定位，达到后像固定定位。

43. 什么是浮动？

答案：
浮动最初用于文字环绕图片，也被早期大量用于布局，但现在常被 Flex 和 Grid 替代。

44. 如何清除浮动？

答案：
常见方式有清除元素、伪元素清除和触发 BFC。

45. Flex 布局适合什么场景？

答案：
适合一维布局，如横向或纵向排列、居中对齐和分布控制。

46. Grid 布局适合什么场景？

答案：
适合二维布局，如页面区域划分、表格式模块和复杂卡片排列。

47. Flex 中 justify-content 的作用是什么？

答案：
它控制主轴方向上项目的对齐和分布方式。

48. Flex 中 align-items 的作用是什么？

答案：
它控制交叉轴方向上项目的整体对齐方式。

49. 如何让元素水平垂直居中？

答案：
常见方式有 Flex 居中、Grid 居中、定位加变换等，现代项目最常用 Flex。

50. gap 有什么作用？

答案：
gap 用于控制 Flex 或 Grid 子项之间的间距，比手动设边距更统一。

响应式与视觉表现

51. 什么是响应式设计？

答案：
响应式设计是让页面在不同设备和屏幕尺寸下都能良好展示和交互。

52. 什么是媒体查询？

答案：
媒体查询允许根据屏幕宽度、方向、分辨率等条件应用不同样式。

53. max-width 和 min-width 的区别是什么？

答案：
max-width 常用于桌面优先向下兼容；min-width 常用于移动优先逐步增强。

54. 什么是移动优先？

答案：
移动优先是先为小屏设备设计基础样式，再逐步增强到更大屏幕。

55. 相对单位有哪些？

答案：
常见有 %、em、rem、vw、vh 等。

56. em 和 rem 的区别是什么？

答案：
em 相对当前元素字体大小，rem 相对根元素字体大小。

57. vw 和 vh 的作用是什么？

答案：
它们分别相对视口宽度和高度，常用于全屏布局和响应式尺寸控制。

58. 什么是 CSS 变量？

答案：
CSS 变量通过 --name 定义，可复用主题值、间距、颜色等设计令牌。

59. calc() 的作用是什么？

答案：
calc() 用于在 CSS 中进行简单计算，适合动态尺寸组合。

60. 什么是过渡 transition？

答案：
过渡用于让属性变化在一段时间内平滑完成。

61. 什么是动画 animation？

答案：
动画通过 @keyframes 定义关键帧，可实现更复杂的连续变化效果。

62. transform 常见用途有哪些？

答案：
常用于位移、旋转、缩放和倾斜，并且通常性能优于直接改布局属性。

63. 为什么动画常推荐用 transform 和 opacity？

答案：
因为它们通常更容易由浏览器进行合成层优化，性能更好。

64. 什么是层叠上下文？

答案：
层叠上下文决定元素的堆叠顺序和 z-index 生效范围。

65. z-index 为什么有时不生效？

答案：
因为元素可能不在同一层叠上下文中，或没有形成可定位上下文。

实战与工程化

66. 什么是 CSS Reset？

答案：
CSS Reset 用于清除浏览器默认样式差异，建立统一的样式基线。

67. Normalize.css 和 Reset 的区别是什么？

答案：
Normalize 更偏保留合理默认样式并做统一，Reset 更倾向完全清空默认样式。

68. 什么是 CSS Modules？

答案：
CSS Modules 通过局部作用域避免类名冲突，适合组件化开发。

69. 什么是 BEM 命名规范？

答案：
BEM 是一种 CSS 类命名方法，通过 Block、Element、Modifier 提升可维护性。

70. 为什么大型项目需要命名规范？

答案：
因为规范能减少样式冲突、提升协作效率并增强代码可读性。

71. 什么是预处理器？

答案：
预处理器如 Sass、Less 提供变量、嵌套、混入等能力，提高样式开发效率。

72. Sass 的常见优势是什么？

答案：
它支持变量、嵌套、函数、混入和模块化能力，适合中大型样式工程。

73. 什么是后处理器？

答案：
后处理器在 CSS 编译后再做转换，如自动加前缀、压缩和兼容性处理。

74. Autoprefixer 的作用是什么？

答案：
它根据浏览器兼容配置自动补全厂商前缀。

75. 什么是 Tailwind CSS？

答案：
Tailwind CSS 是一种原子化 CSS 框架，通过大量工具类快速组合界面样式。

76. 原子化 CSS 的优缺点是什么？

答案：
优点是开发快、复用强、样式一致；缺点是类名较多，初学者阅读成本较高。

77. 什么是关键渲染路径？

答案：
关键渲染路径是浏览器从下载资源到生成可交互页面的核心流程。

78. 为什么 CSS 会阻塞渲染？

答案：
因为浏览器在构建渲染树前需要先拿到关键样式，避免页面闪烁和布局不稳定。

79. 如何优化 CSS 加载性能？

答案：
可以压缩、拆分、按需加载、减少冗余规则和提取关键 CSS。

80. 为什么要减少重排和重绘？

答案：
因为频繁布局和绘制会影响页面性能和交互流畅度。

81. 什么是重排？

答案：
重排是元素几何属性变化后，浏览器重新计算布局的过程。

82. 什么是重绘？

答案：
重绘是元素样式变化但不影响布局时，浏览器重新绘制视觉表现的过程。

83. 哪些操作更容易触发重排？

答案：
如修改宽高、位置、字体大小、插入删除节点和读取某些布局属性后再写入。

84. 什么是雪碧图？

答案：
雪碧图是把多个小图合并到一张图中，通过背景定位减少请求次数的优化方式。

85. 现代项目中雪碧图还常用吗？

答案：
使用频率下降了，很多场景已被 SVG、Icon Font 或组件化图标方案替代。

常见问题与面试表达

86. 什么是 SEO 友好的 HTML 结构？

答案：
它通常具有清晰语义、合理标题层级、可读文本内容和规范元信息。

87. 为什么按钮操作应优先使用 button 而不是 div？

答案：
因为 button 自带语义、可聚焦和键盘交互支持，更符合无障碍和可维护性要求。

88. 图片懒加载有什么意义？

答案：
它能减少首屏资源加载压力，提升首屏速度和节省带宽。

89. 什么是响应式图片？

答案：
响应式图片通过不同资源和尺寸适配不同设备，常结合 srcset、sizes 使用。

90. overflow: hidden 常见用途有哪些？

答案：
可用于裁剪溢出内容、触发 BFC、隐藏滚动条区域外元素等。

91. 什么是文本溢出省略号？

答案：
通常通过 overflow: hidden、text-overflow: ellipsis 和 white-space: nowrap 实现单行省略。

92. 多行文本省略常见怎么做？

答案：
常见用 -webkit-line-clamp 配合弹性盒相关属性实现。

93. 什么是 aspect-ratio？

答案：
aspect-ratio 用于声明元素宽高比，简化图片和卡片比例控制。

94. 为什么样式抖动会影响体验？

答案：
因为布局突然变化会影响用户点击和阅读，增加 CLS 等体验指标风险。

95. 什么是 CLS？

答案：
CLS 是累计布局偏移指标，用于衡量页面加载过程中布局稳定性。

96. 如何减少布局偏移？

答案：
可以为图片和异步内容预留尺寸，避免后加载内容把页面挤动。

97. 面试中如何回答 Flex 和 Grid 的取舍？

答案：
可以说 Flex 更适合一维排列，Grid 更适合二维区域布局，实际项目往往搭配使用。

98. 面试中如何系统回答 CSS 问题？

答案：
可以按原理、布局模型、适用场景、兼容性和性能注意点来组织答案。

99. 面试中如何系统回答 HTML5 问题？

答案：
可以围绕语义化、表单、多媒体、存储、离线能力和 Web API 扩展来展开。

100. 如何总结 CSS / HTML5 的核心价值？

答案：
HTML5 负责结构和语义，CSS 负责表现和布局，二者共同决定页面的可读性、可用性和用户体验。

现代 CSS 特性

101. 什么是 CSS 容器查询（Container Queries）？

答案：
容器查询允许根据父容器的尺寸（而不是视口）来应用样式，使用 @container 规则。父元素需声明 container-type: inline-size。比媒体查询粒度更细，让同一个组件在不同容器宽度下有不同表现，实现真正的组件级响应式，无需修改父级结构。

102. CSS clamp() 有什么作用？

答案：
clamp(min, preferred, max) 在最小值和最大值之间动态计算值。典型用法：font-size: clamp(14px, 2vw, 20px) 让字体随视口缩放但不超出范围，无需媒体查询。常用于响应式字号、间距和容器宽度，实现流体设计。

103. 什么是 CSS 逻辑属性？

答案：
逻辑属性用逻辑方向（block/inline、start/end）代替物理方向（top/left），如 margin-inline-start 代替 margin-left，padding-block-end 代替 padding-bottom。在多语言（LTR/RTL）场景自动适配书写方向，无需为不同语言单独覆盖物理方向样式。

104. 什么是 :is() 和 :where() 伪类？

答案：
:is() 接受选择器列表，匹配其中任一选择器的元素，优先级取参数中最高的选择器；:where() 功能相同但优先级始终为 0，不影响整体权重。二者都可简化重复选择器，如 :is(h1, h2, h3) a 代替三条重复规则。

105. 什么是 CSS Scroll Snap？

答案：
Scroll Snap 让滚动在特定位置自动吸附停止，在容器设 scroll-snap-type，子元素设 scroll-snap-align。无需 JavaScript 即可实现轮播、全屏分页滚动、横向卡片吸附等体验，性能比 JS 监听方案更好。

106. display: contents 有什么作用？

答案：
display: contents 让元素自身不生成盒子（相当于"透明"），但其子元素正常渲染。常用于在 Flex/Grid 容器中插入语义化包装元素而不影响布局，如 <ul> 加 display: contents 后其 <li> 直接参与外层 Grid 布局。

107. 什么是 CSS Subgrid？

答案：
Subgrid 允许子元素继承祖先 Grid 容器的行列轨道，通过 grid-template-columns: subgrid 声明。解决了嵌套 Grid 中内层元素难以与外层对齐的问题，常用于卡片列表中标题、内容、操作区跨卡片对齐的场景。

108. aspect-ratio 属性有什么用？

答案：
aspect-ratio: 16/9 声明元素固定宽高比，当设置宽度后高度自动按比例计算，无需传统的 padding-top 百分比黑客技巧。常用于图片占位、视频容器、头像框、卡片等需要固定比例的元素。

109. 什么是 CSS @layer（级联层）？

答案：
@layer 允许将样式分组到具名层中，并通过 @layer base, components, utilities 声明层的优先级顺序。高层级的样式总是覆盖低层级，无论选择器权重如何。解决了第三方库样式权重难以覆盖、工具类 vs 组件样式冲突等问题，是现代 CSS 架构的重要新工具。

110. CSS color-scheme 和深色模式适配有什么最佳实践？

答案：
通过媒体查询 @media (prefers-color-scheme: dark) 检测系统深色模式并应用变量：在 :root 定义亮色变量，在媒体查询内覆盖为深色值。结合 color-scheme: light dark 让表单控件、滚动条等浏览器原生元素也自动适配。也可配合 data-theme 属性实现手动切换。

总结

这些题目覆盖了 HTML5 语义化、表单与多媒体、CSS 基础、盒模型、布局、响应式、性能优化、工程实践以及现代 CSS 新特性，适合作为前端基础面试系统复习资料。
